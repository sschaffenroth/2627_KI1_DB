# 2627_KI1_DB
Programme im Unterricht der Klasse KI1 im Jahrgang 2026_2027

# How to work
## Vorbereitung:
1. Erstellen eines eigenen Branches mit eigenem Namen
2. Name für GIT festlegen: git config --global user.name "Mona Lisa"
3. Email für GIT festlegen: git config --global user.mail "mona.lisa@yahoo.com"

## Daily work:
1. Lehrer pusht Änderungen nach main
2. Schüler klickt auf "Fetch From All Remotes"
3. Schüler klickt auf die drei Punkte neben "Changes" -> "Branch" -> "Merge" -> "main"
4. Kopie der neuen Datei machen und in Kopie die eigene Lösung schreiben
5. Optional: Push in eigenen Branch (Sync)
